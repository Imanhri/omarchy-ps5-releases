# Changelog

## 1.1.0

- Added an in-popup Game Details view with artwork, the official IGDB description, and available genre, company, platform, and rating metadata.
- Added Back navigation that keeps the selected tab, month, and scroll position, plus a validated View on IGDB action.
- Added on-demand asynchronous detail fetching with a separate six-hour cache by game ID.
- Fixed detail-view click and visibility issues while preserving the existing PS5 release filtering and monthly rankings.
